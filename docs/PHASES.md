# Implementation Phases

## Phase 0: Foundation

Completion criteria:

- Project structure exists.
- Research-only scope is documented.
- MVP stack and success metrics are documented.
- `.env.example` exists with required settings.
- Minimal FastAPI app has `/health`.
- Smoke test passes.
- CI workflow exists.

## MVP Priority

1. Data ingestion
2. Data quality and reliability
3. Database and feature store
4. Strategy registry
5. Realistic backtesting
6. Research dashboard

## Deferred Work

Advanced AI, RL, GNN, meta-learning, Kubernetes, and live-trading-adjacent workflows are deferred until the MVP proves data quality and backtesting reliability.
